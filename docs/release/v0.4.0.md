# OfferFlow v0.4.0 Release Notes

## 主题

v0.4.0 重做为：本地 Node 后端 + 项目内 SQLite 数据库。

旧 v0.4 / v0.5 的 Tauri、Rust、localService、桌面路线已废弃。

## 技术栈

```txt
Vue + Vite + TypeScript
Node.js + Fastify
better-sqlite3 + SQLite
```

DB 文件：

```txt
data/offerflow.sqlite3
```

## 新增能力

1. Fastify 本地 HTTP API，监听 `127.0.0.1:17365`
2. Profile CRUD：`GET /profile`、`PUT /profile`、`DELETE /profile`
3. Jobs CRUD：`GET /jobs`、`POST /jobs`、`GET /jobs/:id`、`PUT /jobs/:id`、`PATCH /jobs/:id`、`DELETE /jobs/:id`
4. localStorage JSON 备份 preview / apply 导入
5. `npm run dev` 一条命令同时启动后端和前端
6. `npm run import:backup -- path/to/backup.json` 导入浏览器备份
7. 前端 profile / jobs 主流程改走 HTTP API

## 不做

1. 不做云同步
2. 不做账号 / 登录
3. 不接 AI API / BYOK
4. 不做 Boss 自动化
5. 不做远程数据库
6. 不继续 Tauri / Rust / localService 路线

## 验证

本版本新增：

```bash
npm exec tsx -- scripts/backendApi.selftest.ts
npm exec tsx -- scripts/importBackup.selftest.ts
```

同时保留：

```bash
npm run typecheck
npm run build
npm run selftest
```

真实浏览器 localStorage 备份如不在仓库内，可由用户在本机执行：

```bash
npm run import:backup -- path/to/offerflow-web-backup.json
```
