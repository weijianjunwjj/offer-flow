## 2. 必须交付结果

### RC-01 BOSS 当前页采集

用户在 Chrome / Edge 的 BOSS 岗位详情页点击一次，可进入 OfferFlow 预览，无需截图。

**通过：** URL、标题、可见 JD、稳定来源信息和可靠字段进入预览；用户确认后写入。  
**不通过：** 只能复制粘贴；扩展直接写正式数据；读取其他标签页或凭据。

### RC-02 通用当前页降级

非 BOSS 岗位页可读取当前页 URL、标题与可见文本进入预览。

**通过：** 无法可靠识别字段保持未知。  
**不通过：** 为了显得完整而补造公司、薪资或职责。

### RC-03 采集入口收敛与统一预览

V8-2 只提供浏览器扩展当前页采集入口；BOSS 定向采集与通用可见文本降级共用预览、纠错和确认链路。

**通过：** 页面不存在手工 JD 文本、链接组合或 JSON 对象/数组输入；未识别字段保持未知；用户确认前不写入 Candidate。
**不通过：** 重新暴露任一手工导入入口；新建长期导入批次主线或 `/radar/imports` 页面。

### RC-04 不可变来源与候选版本

保存不可变 CaptureSnapshot 与 CandidateVersion；手动纠错和实质变化均创建新版本。

**不通过：** 通过 UPDATE 覆盖历史标准化字段；只有 hash 没有可恢复内容。

### RC-05 重复与变化

系统区分确定重复、疑似重复、未变化和实质变化。

**通过：** 未变化不重复分析；疑似重复由用户确认；变化创建新版本并展示 Diff。

### RC-06 透明规则预检

硬约束、风险、偏好和状态抑制分开，并展示命中原文、解释、严重度与用户覆盖。

### RC-07 可解释单岗位分析

复用 v0.7 正式上下文，输出四档建议、证据、反证、缺口、风险和不确定性。

**不通过：** AI 返回系统 ID；虚构经历；排序分伪装成概率；缺少必需输入仍强行输出高置信结论。

### RC-08 0～8 条推荐

用户选择 5～20 条岗位后，系统收敛为 0～8 条重点机会。

**不通过：** 为凑数降低标准；使用 stale 分析；同一岗位重复占位。

### RC-09 误区结果

每批输出一个结果：主要筛选误区，或证据不足及缺失证据。

**不通过：** 样本不足仍强行评价用户职业方向；诊断自动修改正式画像。

### RC-10 雷达动作

收藏、忽略、重点、已投递待反馈及撤销以 Action 流水保存。

**不通过：** 在 Candidate 上保存混合处理状态；新建影子 Application 表。

### RC-11 正式晋升

高价值现实进展或用户明确要求后，预览并幂等关联/创建现有 Job、Application 和 FeedbackEvent。

**不通过：** 无回复自动创建拒绝；撤销雷达动作删除正式事实。

### RC-12 可靠任务与发布验收

任务持久化、幂等、明确失败、一次结构修复、手动重试、取消、刷新恢复和重启后记录恢复；通过评测、migration、备份和恢复。

**不通过：** 宣称 LLM HTTP 请求真正断点续跑；遗留 running 永久卡住；重复写入正式分析。

## 3. 明确排除

- 猎聘专用适配；
- 自动翻页、后台扫描、定时运行；
- 自动投递和联系招聘方；
- SourceConfig / SourceRun；
- 岗位下架恢复；
- 反馈自动提取证据与画像进化；
- 独立 Worker、队列和完整 Agent Runtime；
- 多用户、同步与商业化部署。

---

## 4. 版本完成判定

v0.8 只有同时满足以下条件才可宣称完成：

1. RC-01～RC-12 全部通过；
2. Traceability 中不存在未批准缺口；
3. 30 条评测集与真实端到端剧本通过；
4. 数据库副本 migration、备份与恢复通过；
5. 核心页面真实截图和产品文案通过用户验收；
6. 用户明确批准发布。

---

## 5. 授权边界

签收本合同只代表允许进入 v0.8 代码实施，不自动授权：

- 合并 main；
- 推送 main；
- Tag；
- Release。

以上动作仍需分别明确授权。
